# Remove a volume

{% hint style="warning" %}
You can only remove a volume that is free and has been [detached from any applications that use it](../applications/detach-volume.md).
{% endhint %}

From the menu select **Volumes**, tick the checkbox next to the persistent volume, persistent volume claim or storage class you want to remove then click **Remove**.

<figure><img src="../../../.gitbook/assets/2.42-remove-a-volume.gif" alt=""><figcaption></figcaption></figure>

When the confirmation message appears, click **Remove**.

<figure><img src="../../../.gitbook/assets/2.15-k8s-volumes-remove-confirm.png" alt=""><figcaption></figcaption></figure>
